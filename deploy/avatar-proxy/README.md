# Grafit Avatar Proxy

Маленький сервис на чистом Python (без единой внешней зависимости), который
ставится **на серверный ПК**, рядом с `GizmoService.exe`, и решает одну
задачу: даёт клиентской оболочке возможность прочитать/загрузить аватарку
пользователя, не имея прав на управленческий REST API Gizmo напрямую.

## Почему так

`PUT/GET /api/v3/users/{id}/picture` в Gizmo API — это часть **management**
API (тот же, что использует Gizmo Manager), доступ к нему даёт только
оператор-логин (учётка сотрудника), а не сессия обычного клиента. Оболочка
на станции никогда не должна знать пароль оператора — вместо этого она
стучится в этот локальный прокси по простому адресу
`http://<сервер>:8765/avatar/{userId}`, а прокси уже сам:

1. держит логин/пароль оператора в `config.json` на сервере (клиенты его
   никогда не видят);
2. обменивает его на токен через `/api/v3/auth/accesstoken` (сам обновляет,
   когда токен истекает);
3. дергает `/api/v3/users/{id}/picture` от имени этого оператора.

Так все "костыли" авторизации остаются в одном месте на сервере, а клиенту
достаточно позвать `GET`/`POST /avatar/{id}` без каких-либо секретов.

## Установка

1. Скопируй всю папку `avatar-proxy` на серверный ПК (например,
   `C:\NETProjects\avatar-proxy`).
2. Скопируй `config.example.json` → `config.json`, впиши туда:
   - `operator_username` / `operator_password` — логин/пароль **оператора**
     Gizmo (учётка, которой заходишь в Gizmo Manager). Убедись, что у роли
     этого оператора есть право на просмотр/редактирование пользователей.
   - `branch_id` / `register_id` — оставь `null`, если у тебя одна точка
     (не мультифилиальная конфигурация).
3. Убедись, что Python 3.8+ установлен (или собери `avatar_proxy.exe` через
   PyInstaller — см. ниже, тогда Python на сервере вообще не нужен).
4. Проверь руками: `run.bat` — должно появиться
   `Grafit avatar proxy listening on 0.0.0.0:8765 -> http://localhost/api/v3`.
   Открой `http://localhost:8765/health` в браузере — должно быть `{"status":"ok"}`.
5. Чтобы прокси поднимался сам при перезагрузке сервера и перезапускался при
   падении — от имени администратора запусти `install-autostart.ps1`. Это
   регистрирует Scheduled Task (не настоящий Windows Service, но ведёт себя
   так же: без окна, стартует при загрузке системы, сам перезапускается).

## Сборка в exe (чтобы не ставить Python на сервер)

```
pip install pyinstaller
pyinstaller --onefile --name avatar_proxy avatar_proxy.py
```

Готовый `dist\avatar_proxy.exe` положи рядом с `config.json` в эту же папку
— `install-autostart.ps1` и `run.bat` сами его подхватят вместо `.py`.

## Порт и firewall

По умолчанию слушает `0.0.0.0:8765` — то есть его видно со всех станций в
локальной сети клуба, но НЕ через `localhost` шеллы других машин. Если
Windows Firewall на сервере блокирует входящие — один раз разреши порт 8765
(TCP, входящее) для приватной сети.

## Логи

`avatar_proxy.log` в этой же папке — туда пишутся все запросы и ошибки
обмена токеном (без самого пароля/токена в открытом виде).

## Endpoints (для справки — оболочка обращается к ним сама)

- `GET /avatar/{userId}` → сырые байты картинки (`image/jpeg`/`webp`/`png`),
  или 404 если аватарки нет.
- `POST /avatar/{userId}` → тело запроса — уже сжатая на клиенте картинка
  (максимум 2 МБ на уровне прокси, по факту клиент шлёт десятки КБ).
- `GET /avatar/{userId}/nudge` → `{"show": true|false}` — решает, показывать
  ли клиенту без аватарки баннер "добавь фото". Ответ — чистая проверка по
  локальному файлу `avatar_index.json` (без похода в Gizmo API), поэтому
  мгновенная даже при паре тысяч аккаунтов. Первый логин — всегда `true`,
  дальше — раз в `nudge_interval_logins` логинов (по умолчанию 5, настройка
  в `config.json`). Как только у пользователя появляется аватарка —
  навсегда `false`.
- `GET /health` → `{"status":"ok"}`, для проверки что прокси жив.

## Файл-индекс

`avatar_index.json` рядом со скриптом — сам себя наполняет из обычного
трафика (`GET`/`POST /avatar/...`), отдельного бэкафилла не нужно. На ~5000
аккаунтов это файл в районе сотен КБ, читается в память один раз при
старте.
